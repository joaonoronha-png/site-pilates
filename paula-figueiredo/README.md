# Paula Figueiredo — Cerimonial e Decoração de Eventos (site demonstrativo)

Mesmo modelo do site da Rebecca Gemaque (HTML + CSS + JS puro, GSAP + Lenis), com identidade própria:
- cores tiradas do logotipo (creme, listras areia, marrom-dourado);
- tipografia Playfair Display + Jost.

Para abrir: dê dois cliques em `index.html` ou publique a pasta arrastando-a para app.netlify.com/drop.
