# Imagens reais — Nael Jr Barber Studio

Coloque os arquivos reais (extraídos do Instagram @naeljrbarberstudio) exatamente
com estes nomes. Assim que o arquivo existir, o placeholder editorial desaparece
automaticamente — nenhuma alteração de código é necessária.

| Arquivo               | Uso                                             | Proporção sugerida |
|------------------------|--------------------------------------------------|---------------------|
| `hero-main.jpg`        | Capa do Hero (foto/vídeo de impacto)             | vertical ou 4:5     |
| `trabalho-01.jpg`      | Trabalhos — peça vertical grande                 | 3:4                 |
| `trabalho-02.jpg`      | Trabalhos — Nael trabalhando (horizontal)        | 16:9                |
| `trabalho-03.jpg`      | Trabalhos — detalhe de corte                     | 1:1                 |
| `trabalho-04.jpg`      | Trabalhos — detalhe de barba                     | 1:1                 |
| `trabalho-05.jpg`      | Trabalhos — resultado final (horizontal)         | 16:9                |
| `nael.jpg`              | Seção Nael Junior — foto forte de Nael trabalhando | 4:5                |
| `studio-01.jpg`        | Seção Studio — ambiente                          | 4:3                 |
| `studio-02.jpg`        | Seção Studio — ambiente                          | 4:3                 |
| `studio-poster.jpg`    | Capa (poster) do vídeo do Studio                 | 16:9                |

Comprima os arquivos (WebP/JPEG otimizado, idealmente < 300KB cada) antes de subir,
para manter o carregamento rápido no celular.
